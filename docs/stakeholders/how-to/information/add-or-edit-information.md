# Add or edit Information content

> **Status:** In progress  
> **Who:** Leaders (including area admins, and later site admins) — **not** guests or ordinary members  
> **Where:** **CTRIM** tab — About, Churches, Testimonials, Information pages

## Before you start

- Confirm you see **Add** / **Edit** controls (if you don’t, you don’t have access)  
- Prefer the **web app** for writing longer text  

## Add a record

1. Open the **CTRIM** tab.  
2. Go to the right subsection (**Churches**, **Testimonials**, or **Information**).  
3. Choose **Add** (or equivalent).  
4. Fill in title and body (rich text).  
5. Save and check how it looks when viewing as a normal reader.  

## Edit an existing record

1. Open the item from the list.  
2. Choose **Edit**.  
3. Update the content.  
4. Save.  

## Delete *(if available)*

1. Open the item.  
2. Use **Delete** only when you are sure — confirm any prompt.

# Screenshot checklist

One list of images to capture for this product guide. Drop files in `docs/stakeholders/assets/` using the **filename** in each row — then paste them in (see [Using images, GIFs, and video](media.md)).

This page is for whoever is taking the shots. It is not in the public site nav.

## How to capture

- Use the **web app** (desktop browser). About **1280px** wide, **light** appearance, unless a row says otherwise.
- Crop to the useful UI (tabs, cards, editor). Browser chrome is optional.
- Avoid unpublished personal data: emails, phone numbers, private notes. Dummy names are fine.
- PNG or WebP. Keep each file under ~500 KB if you can.
- Optional GIFs: 5–12 seconds, looping, one task.

**Do first:** the four **Home** shots. Those carry the landing page. How-to steps next. Feature-page extras last.
